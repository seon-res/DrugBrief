# DrugBrief — 의약품 허가·임상시험·규제 동향

FDA의 의약품 허가 기록, ClinicalTrials.gov의 임상시험 정보, FDA·EMA·식약처의 규제 및 가이드라인 자료를 한곳에서 검색하고 비교할 수 있도록 정리한 개인 프로젝트입니다.
공식 API와 공개 자료를 활용해 데이터를 정기적으로 수집하고, 의약품 개발부터 허가 및 규제 변화까지 한눈에 확인할 수 있도록 구성했습니다.

## 사이트: https://seon-res.github.io/DrugBrief/

## 왜 만들었나

제약·바이오 산업을 공부하면서 새롭게 허가된 의약품이 무엇인지, 어떤 임상시험이 진행되고 있는지, 관련 규제는 어떻게 달라지고 있는지 꾸준히 확인하고 싶었습니다.

하지만 FDA의 의약품 허가 정보, ClinicalTrials.gov의 임상시험 정보, 각 규제기관의 가이드라인이 서로 다른 사이트에 흩어져 있어 매번 찾아보기가 번거로웠습니다. 특히 의약품의 허가 내용이나 임상시험 진행 상황을 확인하려면 여러 자료를 따로 검색해야 했습니다.

그래서 관련 정보를 한곳에 모으고 수집 과정을 자동화해, 제약·바이오 산업의 주요 변화를 지속적으로 확인할 수 있도록 만들었습니다.

## 어떻게 쓰나

- 의약품 허가·승인: FDA의 NDA·BLA 원허가 기록을 검색하고, 의약품명·제약사·승인일·허가 관련 설명 확인
- 임상시험 현황: 의약품 및 바이오의약품 임상시험의 Phase, 모집 상태, 개발사, 대상 질환, NCT 번호 확인
- 규제·가이드라인: FDA·EMA·식약처 관련 규제 자료를 키워드와 기관별로 검색하고 과거 기록과 비교
- 검색 및 통계: 의약품명·기업명·질환명·기관명 등으로 검색하고, 유형별 건수와 분포 확인
- 원문 확인 및 다운로드: 개별 자료의 공식 출처로 이동하거나 검색 결과를 CSV 파일로 다운로드
- 정기 자동 갱신: GitHub Actions를 통해 공식 데이터를 매일 수집하도록 설정하고, 수집 성공 여부와 갱신 시각 표시

## 수집 범위

**1. 의약품 허가·승인**

FDA의 openFDA Drugs@FDA API를 활용합니다. 2015년부터의 NDA·BLA 최초 신청 승인(Original Approval) 기록을 수집하며, 제네릭 의약품의 ANDA 및 보완 신청은 제외합니다.

개별 의약품에 대해서는 FDA 승인서 또는 공개 제품설명서에 근거한 설명을 제공하며, 승인서 검토 완료 여부와 자동 발췌 여부를 구분합니다.

**2. 임상시험 진행 현황**

ClinicalTrials.gov API v2를 활용해 최근 변경된 의약품 및 생물학적 제제 중재시험 정보를 최대 200건 수집합니다. 임상 단계, 진행 상태, 개발사, 대상 질환 등을 확인할 수 있습니다.

**3. 제약 규제·가이드라인**

FDA Federal Register와 EMA의 규제·과학 가이드라인 RSS를 통해 신규 자료를 수집합니다. 
2015년부터의 식약처 및 해외 규제기관 자료도 함께 검색할 수 있도록 구성했습니다.


**수집 범위 및 한계:** FDA 원허가 기록은 FDA의 혁신 신약(Novel Drug Approvals) 목록과 동일하지 않습니다. 임상시험 자료는 최근 변경된 일부 기록이며, 전체 임상시험을 의미하지 않습니다. 기존 식약처 규제 자료는 2026년 10월 15일 기준 스냅샷으로, 현재 신규 자동 수집 대상에는 포함되지 않습니다.

## 구조

GitHub Actions가 Python 수집 스크립트를 실행해 openFDA, ClinicalTrials.gov, FDA Federal Register, EMA의 공식 데이터를 가져옵니다. 수집한 자료는 JSON 파일로 저장하고, HTML·CSS·JavaScript 기반의 정적 웹사이트를 GitHub Pages에 배포합니다.

매일 한국시간 오전 10시 27분에 자동 갱신을 예약해 두었으며, GitHub 실행 환경이나 기관별 API 상태에 따라 실제 갱신 시각은 달라질 수 있습니다.

일부 기관의 수집에 실패하면 마지막으로 저장된 데이터를 유지하고, 수집 상태를 사이트에 표시하도록 구성했습니다. 별도의 AI API 없이 동작하며, 공개된 공식 자료를 쉽게 탐색할 수 있도록 하는 데 초점을 맞췄습니다.
